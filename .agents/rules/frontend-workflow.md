# Frontend Workflow & Trash Policy

Whenever you make any changes to the frontend UI or UX, you MUST:
1. Provide a clear "Before" and "After" description of the changes.
2. Use the `browser_subagent` to capture screenshots of the updated UI to present to the user.
3. NEVER permanently delete old components, CSS files, or unused files. Instead, move them to the corresponding `_trash/frontend/`, `_trash/backend/`, etc. directories.
